App Development Proposal
High School Theater Technology Project
Target Completion Date: September 5, 2026
Project Type: Functional web application / software prototype
Development Level: High-quality high school project
Primary Goal: Turn one of the concepts below into a polished, usable application that solves a real problem for a high school theater program.

1. Project Overview
We are looking for a development team to take one of two theater-technology concepts and turn it into a functioning application by September 5, 2026.
The finished product should feel substantially more developed than a simple class coding exercise. It should have a clean interface, a coherent user experience, persistent data, and enough functionality to demonstrate that it could genuinely be used by a theater department.
At the same time, the project should remain appropriate for a strong high school student. We are not looking for an enterprise-grade commercial product with dozens of features. The emphasis should be on:
Solving a clearly defined real-world problem
Building a strong and demonstrable core product
Producing a clean, professional UI
Making technically interesting but achievable design decisions
Allowing the student to understand and explain how the application works
Leaving room for future expansion
The development team can advise on which concept is most realistic and compelling given the September 5 deadline.

OPTION 1 — Theater Inventory Tracker
Concept
Build an inventory-management application designed specifically for theater technicians and stage crews.
Large theater productions require significant amounts of equipment and materials: lighting instruments, cables, microphones, tools, set pieces, lumber, hardware, costumes, props, and other technical assets.
The problem is that theater departments often do not have a convenient system for answering basic production questions:
What equipment do we currently have?
Where is it?
What condition is it in?
Is it currently being used?
What will we need for the next production?
What needs to be repaired, replaced, built, or purchased?
The application would give theater technicians a centralized way to manage this information.
